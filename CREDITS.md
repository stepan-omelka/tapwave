# Music credits

Every song in Tapwave is either original (the synthesised tracks) or published under an open license that
allows redistributing it inside a game. The audio files in `frontend/public/audio/` are the publishers'
original MP3s, unmodified apart from the file name. The beatmaps (the notes you play) are generated by
Tapwave from each song's measured beat grid; they are not part of the songs.

Tapwave's own code and contain no samples.

The game shows the title, artist, source link and license of every song on the song-select screen.
